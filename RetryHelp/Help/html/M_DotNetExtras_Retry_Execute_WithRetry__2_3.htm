      ExecuteWithRetryE, T(FuncT, FuncT, Boolean, IReloadable, Int32, NullableTimeSpan, ILogger) Method

      Executes code that returns a value and, calling the Reload method, re-executes it until it runs out of attempts if the code either throws a specific exception or the caller-supplied predicate indicates that the result is not acceptable.

      Return Value

      T
      Value returned by the last executed code block (which may still satisfy the retry condition if all attempts were exhausted without an exception being thrown on the final attempt).

      Remarks

      When the attempts are exhausted, the last failure determines the outcome: if the final attempt threw the expected exception, it is rethrown; otherwise, the last returned value is returned.
