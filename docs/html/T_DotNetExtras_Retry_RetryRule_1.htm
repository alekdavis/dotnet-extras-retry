      Remarks

      When the code block fails (throws an exception or returns a value), the rules are evaluated in order and the first matching rule handles the failure. Each rule tracks its own budget independently of the other rules.

      If neither Attempts nor Timeout is set, the rule allows two attempts (one retry). If both are set, the rule is exhausted when either limit is reached.

      When the matching rule is exhausted, the last failure wins: an exception is rethrown and a returned value is returned. A failure that does not match any rule is not retried.

      GetSleep Function that calculates the sleep time before a retry from the returned value (if any) or the thrown exception (if any), such as a value from the Retry-After HTTP header.

      Reload Object whose Reload method is called before each retry triggered by this rule.
      ReloadAsync Object whose ReloadAsync(CancellationToken) method is awaited before each retry triggered by this rule (asynchronous methods only).
      Sleep Fixed sleep time before each retry triggered by this rule.
      Timeout Period of time, measured from the first failure matched by this rule, after which this rule stops retrying.
