      ExecuteWithRetryAsyncT(FuncTaskT, FuncT, Boolean, IReloadable, TimeSpan, NullableTimeSpan, ILogger, CancellationToken) Method

      Asynchronously executes code that returns a value and, if the caller-supplied predicate indicates that the result is not acceptable, calls the Reload method (if the caller is specified) and re-executes it until it runs out of time.
